# TONE Magazine

A full-stack web application for TONE Magazine, built with Laravel and Angular. The platform includes a public-facing magazine website and an admin CMS for managing digital content.

## Project Overview

The project aims to rebuild the TONE Magazine website with a modern, responsive design and an easy-to-use admin panel.

## Features

- Responsive frontend website
- Admin dashboard and CMS
- Story and article management
- Topic and category management
- Digital magazine and PDF downloads
- Newsletter subscription
- Sponsor and partner management
- SEO management
- Analytics and reporting

## Technology Stack

- **Backend:** Laravel / PHP
- **Frontend:** Angular / TypeScript, HTML, CSS, JavaScript, Bootstrap, jQuery
- **Database:** MySQL
- **API**: REST API
- **Version Control:** Git / GitHub

## Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/YOUR-USERNAME/tone-magazine-laravel.git
   ```

2. Navigate to the project directory:

   ```bash
   cd tone-magazine-laravel
   ```

3. Install dependencies:

   ```bash
   composer install
   ```

4. Create the environment file:

   ```bash
   cp .env.example .env
   ```

5. Generate the application key:

   ```bash
   php artisan key:generate
   ```

6. Configure your database details in the `.env` file.

7. Run migrations:

   ```bash
   php artisan migrate
   ```

8. Start the development server:

   ```bash
   php artisan serve
   ```
